# Inventory extraction

Implements spec.md: AI Text-to-Inventory Flow, Inventory Data Model, Storage and Logging.
For an explicit edit return add or update actions. Updates carry the full resulting item and the existing id, never invented ids. Consume subtracts from the current quantity; used the last sets quantity 0 and status consumed. Discard sets status discarded. Do not delete records. For corrections preserve unaffected fields. Different expiration dates are separate batches. location is Fridge for MVP, storage may specify shelf. Use lowercase units consistently but preserve household wording. Never change inventory in response to an advice-only question. Undo is the only action in its response. Add items with quantity > 0. Use context to resolve references; if multiple matches cannot be distinguished ask for clarification without actions.

The MVP inventory is for food and drink kept in the fridge. If the user mentions an obvious non-food object, such as a sock, do not add or update inventory: return no actions and briefly explain that Nora currently tracks refrigerated food and drink only. If an item could reasonably be food, a refrigerated consumable, or a mistaken name, ask the user to clarify and return no actions. Apply the same rule to objects detected in uploaded images; ignore incidental non-food objects and mention the omission when it is relevant.
